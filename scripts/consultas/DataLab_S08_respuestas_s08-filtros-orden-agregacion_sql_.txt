EJERCICIO 7
Consulta / respuesta:
-- Datasets cuyo tamaño es desconocido
SELECT id_dataset, nombre, tamanio_filas
FROM dbo.dataset
WHERE tamanio_filas IS NULL;

-- Datasets cuyo tamaño sí está informado
SELECT id_dataset, nombre, tamanio_filas
FROM dbo.dataset
WHERE tamanio_filas IS NOT NULL;
Observaciones:
IS NULL encuentra valores ausentes; IS NOT NULL encuentra los valores informados. NULL no se debe comparar con = NULL.

EJERCICIO 9
Consulta / respuesta:
-- Forma 1
SELECT id_dataset, nombre, fuente
FROM dbo.dataset
WHERE fuente <> N'externa';

-- Forma 2
SELECT id_dataset, nombre, fuente
FROM dbo.dataset
WHERE NOT (fuente = N'externa');
Observaciones:
Para valores no nulos, ambas formas devuelven las fuentes distintas de externa. En SQL Server, ambas también excluyen las filas donde fuente es NULL, porque la comparación con NULL no resulta verdadera.

----------------------------------------

EJERCICIO 16
Consulta / respuesta:
SELECT nombre_metrica, AVG(valor) AS promedio
FROM dbo.metrica
GROUP BY nombre_metrica
HAVING AVG(valor) > 0.80;
Observaciones:
HAVING filtra los grupos después de calcular el promedio. AVG(valor) no debe ir en WHERE porque WHERE filtra filas antes de agrupar.

EJERCICIO 17
Consulta / respuesta:
INSERT INTO dbo.proyecto (nombre_proyecto, descripcion)
VALUES (N'Proyecto S08 - Prueba estudiante',
        N'Registro temporal creado para el ejercicio 17 de Semana 8.');

SELECT id_proyecto, nombre_proyecto, descripcion
FROM dbo.proyecto
WHERE nombre_proyecto = N'Proyecto S08 - Prueba estudiante';
Observaciones:
INSERT crea el proyecto y SQL Server genera id_proyecto automáticamente si es una columna IDENTITY. El SELECT permite verificar el registro. Si el nombre ya existe, usa otro nombre único.

----------------------------------------

EJERCICIO 18
Consulta / respuesta:
-- Verificar antes de modificar
SELECT id_proyecto, nombre_proyecto, descripcion
FROM dbo.proyecto
WHERE nombre_proyecto = N'Proyecto S08 - Prueba estudiante';

-- Actualizar la descripción
UPDATE dbo.proyecto
SET descripcion = N'Descripcion actualizada para el ejercicio 18 de Semana 8.'
WHERE nombre_proyecto = N'Proyecto S08 - Prueba estudiante';

-- Verificar después de modificar
SELECT id_proyecto, nombre_proyecto, descripcion
FROM dbo.proyecto
WHERE nombre_proyecto = N'Proyecto S08 - Prueba estudiante';
Observaciones:
Se consulta primero el proyecto, se modifica solo la descripción de ese nombre y se vuelve a consultar para comprobar el cambio. El WHERE evita actualizar otros proyectos.

----------------------------------------

EJERCICIO 19
Consulta / respuesta:
-- Verificar que sea el proyecto de prueba
SELECT id_proyecto, nombre_proyecto
FROM dbo.proyecto
WHERE nombre_proyecto = N'Proyecto S08 - Prueba estudiante';

-- Eliminar exclusivamente el proyecto creado en el ejercicio 17
DELETE FROM dbo.proyecto
WHERE nombre_proyecto = N'Proyecto S08 - Prueba estudiante';

-- Comprobar que ya no exista
SELECT id_proyecto, nombre_proyecto
FROM dbo.proyecto
WHERE nombre_proyecto = N'Proyecto S08 - Prueba estudiante';
Observaciones:
El último SELECT debería devolver cero filas si la eliminación se realizó correctamente. Ejecuta este ejercicio después del 17 y el 18. No lo ejecutes si el nombre corresponde a un registro que no creaste; una clave foránea también podría impedir eliminarlo.

----------------------------------------
